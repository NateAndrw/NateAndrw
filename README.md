# Hi, I'm Nathan Andrew

I design and build **embedded systems and electronics**: from logic-gate computers on breadboards to custom PCBs, firmware and 3D-printed enclosures.

## What I work with

![C++](https://img.shields.io/badge/C%2B%2B-Arduino%20%2F%20ATmega328P-00979D?logo=arduino&logoColor=white)
![PCB](https://img.shields.io/badge/PCB-EasyEDA-blue)
![Digital](https://img.shields.io/badge/digital%20logic-74xx%20%2F%204000-orange)
![3D printing](https://img.shields.io/badge/3D%20printing-enclosures-lightgrey)

- **Firmware:** C/C++ on ATmega328P and Arduino Nano (timers, interrupts, shift registers, SPI, EEPROM)
- **Hardware design:** schematics and PCB layout in EasyEDA, fabricated through JLCPCB, hand-soldered through-hole and SMD
- **Digital and analog circuits:** discrete logic, ALUs, ADC/DAC, oscillators, power regulation
- **Test and measurement:** multimeter and oscilloscope debugging
- **Fabrication:** 3D-printed cases designed to fit each board
